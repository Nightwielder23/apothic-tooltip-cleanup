# Apothic Tooltip Cleanup

A small client-side Minecraft mod that cleans up Apotheosis affix and gem tooltips. Configurable per feature, all off by default.

## Features
- Collapses empty sockets into one summary line
- Hides the "Fits In" section on gem tooltips, or compacts/restructures it
- Sorts affixes alphabetically
- Hides specific affix IDs by translation key
- Toggles Apotheosis's summarization block
- Overrides rarity colors with user-configured hex values
- Truncates the affix list with an Alt-to-expand prompt

## Requirements
- Minecraft 1.21.1
- NeoForge 21.1.187+
- Apotheosis 8.0.0+ (soft dependency, mod does nothing without it)
